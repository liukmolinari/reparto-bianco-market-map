# Reparto Bianco Market Map — v1D

Mappa web statica, mobile-friendly e senza database/backend.

## Novità
- 493 store caricati: MediaWorld 20, Unieuro 223, Euronics 190, Trony 12, Comet 48
- mappa a tutta altezza: eliminata la fascia grigia inferiore
- loghi reali delle cinque catene
- clustering automatico per gestire centinaia di marker
- filtri catena, macro-area, priorità e Top 25
- aggiunta/rimozione store locale + backup JSON

## Coordinate
I 25 candidati approfonditi mantengono coordinate specifiche già disponibili. Gli altri store sono posizionati sul centro del comune (con un piccolo offset visivo quando più negozi sono nella stessa città): quindi la posizione è indicativa, non un geocoding dell'indirizzo civico.
